# QuiKShot

A fast and comfortable screenshot utility for Windows which supports any version since Windows 95 and NT 4.0, with a user experience largely inspired by ShareX and Lightshot.

## Installing

*QuiKShot is currently in alpha. No precompiled builds are provided at the moment.*

QuiKShot is portable software, so it can just be run from your downloads folder. You can place the QuiKShot files wherever you please.

## Uninstalling

QuiKShot saves user configuration to the registry. If you wish to remove this state, please delete the registry key `HKEY_CURRENT_USER\SOFTWARE\ClaireLostHerPhone\QuiKShot`;
